# LocalAIConsoleAndWeb code sample

Setup Ollama:

- Install Ollama  
- open a Terminal  
- execute `ollama serve`  
- execute `ollama pull phi3:mini`  
- execute `ollama run phi3:mini`  

Then load either the **LocalAIConsole** or **LocalAIWeb** projects.
